# data/

Drop the official APQC PCF export here as `apqc_pcf.xlsx`.

Download: apqc.org → Resource Library → "APQC Process Classification Framework
(PCF) - Cross-Industry - Excel Version 8.0". Free, registration required.

It is not committed to this repository because APQC distributes it under an
attribution licence and requires registration to download. Until it is present,
OpenProcess falls back to its own `OP-IT-*` working taxonomy and says so in the
UI banner — it never displays a number that looks like a real PCF ID unless that
number came out of APQC's own file.
